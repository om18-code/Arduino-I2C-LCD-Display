# Arduino I2C LCD Display

## Project Overview
This project demonstrates how to interface an I2C LCD Display with an Arduino Uno.

## Features
- Display custom messages
- Scrolling text effect
- Simple I2C communication using SDA and SCL

## Components Used
- Arduino Uno
- I2C LCD Display
- Jumper Wires

## Connections

| LCD | Arduino Uno |
|------|------------|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

## Learning Outcomes
- LCD Interfacing
- I2C Communication
- Arduino Programming
